## HARD LESSONS BAKED IN (from the 2026-08-10 session — do not relearn these)

- **Test API behavior through the REAL router by URL, never by importing the handler.** The services
  reorder endpoint 500'd in production for weeks while a green integration test passed — because the test
  imported the route handler directly and bypassed route matching. The actual bug was a static-vs-`[param]`
  route collision (`/services/reorder` was captured by `/services/[serviceId]`). Any endpoint you add or
  fix MUST be exercised via `api.request('/api/...')` so route matching is real. For any new route, verify
  there is no static-vs-dynamic shadowing, and 404 a non-integer id BEFORE it reaches SQL.
- **No internal jargon in user-facing copy.** Never surface words like "capability", "storefront key",
  "RLS" to a business or a pet owner. Plain language only (this is literally ticket 2.90).
