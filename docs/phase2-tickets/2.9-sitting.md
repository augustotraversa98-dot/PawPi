# 2.9 — Pet sitting module (in-home visits / overnight / house-sit)

Read `00-README.md` + `../phase2-superapp-master-plan.md` (§1 sitting row) first. Depends on: 2.1, 2.4,
2.3, 2.5. Capability = `sitter`.

```
ORIENTATION
PawPi web API + mobile. Phase-2 ticket 2.9: the SITTER module — drop-in visits, overnight, and
house-sitting, with visit logs + photo/video updates and a meet-and-greet step. Read
docs/phase2-tickets/00-README.md + master plan. Gate with requireProviderCapability(providerId,'sitter').
Reuse booking (2.4; visit types as services; recurring drop-ins), payments (2.3), chat (2.5), Storage.
Much overlaps the walker/daycare patterns — reuse those table/route shapes where sensible.
Branch ticket/service-sitting off origin/main; squash-merge; migration for visits if needed.
Gates: npm test + npm run test:integration.

GOAL: owner books a sitting service (drop-in / overnight / house-sit) → optional meet-and-greet → sitter
logs each visit with photo/video updates the owner sees.

SCOPE
- Service types via provider_services (capability='sitter'): drop-in visit, overnight, house-sit, with
  duration/price. Booking via 2.4 (single or recurring). Fee via 2.3.
- sitting_visits table (RLS'd): booking_id, pet_id, owner_user_id, provider_id, staff_user_id, visit_at,
  status, notes, photo/video urls[], (optional) location check-in. Sitter posts per-visit updates; owner
  reads. Participant-scoped RLS + harness proofs.
- Meet-and-greet: a lightweight pre-booking step (a special booking status or a flag) so owner + sitter
  align before the engagement; reuse chat (2.5).
- mobile: owner — book + meet-and-greet + see visit updates; sitter — log visits/updates. Discovery
  ?type=sitter under Services → Pet Sitting.
- Tests: capability gate; visit lifecycle + updates; participant RLS; recurring drop-ins.

DO NOT: bypass capability gate; expose visit media to non-participants; rebuild booking/chat. No fake
data.

VERIFY: npm test + integration green. PR body: visit model, meet-and-greet, RLS. Migration (if any)
hand-applied after merge. Confirm origin/main.
```
