CONTEXT — what "modern iOS 27 / Liquid Glass" means here (verified Jun 2026)
- Liquid Glass = Apple's system design language (introduced iOS 26 / WWDC 2025, refined for iOS 27 / WWDC
  2026, where it becomes MANDATORY — Xcode 27 drops the old compatibility modes). Hallmarks: fluid,
  TRANSLUCENT materials with real depth/separation for readability; lighter chrome; tab bars + buttons adopt
  the glass look; iOS 27 tuned it to diffuse busy content behind it better and added a user transparency/
  intensity preference. Honor accessibility: it must stay readable, respect Reduce Transparency + Reduce
  Motion, and not rely on transparency for meaning.
- HONEST CAVEAT: authentic Liquid Glass is a native SwiftUI/system effect. Custom RN-drawn surfaces (e.g. the
  floating tab bar from 2.59/2.60) won't get it automatically — APPROXIMATE with expo-blur + translucency +
  depth + spring motion. Don't claim system-identical glass on custom views; aim for "clearly modern, on-
  trend, smooth."
- "Chunky → smoother" = motion + form work: lighter borders/shadows, softer/larger radii, airier spacing,
  refined type scale, and SPRING-based transitions (screen pushes, sheet/modal present/dismiss, tab switches,
  list item enter/exit, the existing micro-interactions like the 2.64 double-tap paw). Keep it subtle and
  consistent, not bouncy-everywhere.
- KEEP THE COLOR PALETTE. Tats likes it. This redesign changes FORM, MATERIAL, and MOTION — not the hues.
  Source palette stays COLORS (coral #FF6F61, peach, warm brown, sage, cream, sand).
