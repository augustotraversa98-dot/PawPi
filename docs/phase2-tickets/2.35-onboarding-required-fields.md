  sensible @handle format rule (lowercase alphanumerics + underscore, reasonable length) and enforce it.
- Keyboard: wrap the onboarding forms in KeyboardAwareScrollView (or the existing keyboard-safe pattern)
  so focused inputs scroll above the keyboard and the continue button stays reachable. Use the correct
  keyboardType per field.
- Tests: continue is blocked until required fields are valid (and enabled once they are); @handle format
  validation; the screen renders inside the keyboard-safe wrapper.

DO NOT: make everything required (only the essential set); add a migration; change the backend create
shape beyond sending the now-required values it already accepts; break the photo steps.

VERIFY: npm test (mobile) green. DEVICE: can't finish onboarding without @handle + pet name + species;
inputs never hidden by the keyboard.
