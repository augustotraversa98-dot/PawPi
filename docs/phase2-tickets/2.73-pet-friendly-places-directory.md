# 2.73 — Pet-friendly places directory (Wave 7)

Read `00-README.md` (the ⚡ autonomy preamble + shared conventions) first. Mobile + web API + migration. A
discovery surface of pet-friendly places (parks, cafés, hotels, vets-nearby, beaches) sourced from the
**Google Places API** (decided with Tats 2026-06-18) and displayed on the shared **Apple map** (2.68). ⛔
**Build after 2.68**. These are NOT onboarded providers — keep them a lightweight separate entity; do NOT
shoehorn them into the provider spine.
