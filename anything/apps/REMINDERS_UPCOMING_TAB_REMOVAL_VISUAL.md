## User Journey Comparison

### Finding Upcoming Reminders

#### Before
```
User: "What reminders do I have coming up?"

Path: More → Reminders & Routines → Upcoming tab → Scroll endless list

Problems:
- Had to navigate to More tab
- Open Reminders & Routines
- Wait for endless list to load (slow)
- Scroll through 100+ reminders
- No direct actions
```

#### After
```
User: "What reminders do I have coming up?"

Path: Health → Today → Next Up section (top of screen)

Benefits:
- Already on Health tab
- See next 1-3 reminders immediately
- Within next 6 hours (relevant)
- Direct action buttons (Log food, Start walk, etc.)
- Fast load (only 3 items max)
- "Manage routines" link if they want to edit schedule
```

## Performance Comparison

### Before: Endless List
```javascript
// Loaded ALL reminders
const todayReminders = reminders.filter(today); 
// Could be 20+ items for today alone

const upcomingReminders = reminders.filter(upcoming);
// Could be 100+ items for the week

// Rendered:
- All today's reminders
- All tomorrow's reminders  
- All this week's reminders
- All later reminders

Total: 100+ reminder cards rendered
Performance: Slow, laggy scrolling
```

### After: Smart Limit
```javascript
// Only load next 1-3 reminders within 6 hours
const getNextUpReminders = () => {
  return reminders
    .filter(withinSixHours)
    .sort(byTime)
    .slice(0, 3); // MAX 3
};

// Rendered:
- Time-sensitive countdown cards (1-2)
- Next up actionable reminders (1-3)

Total: 3-5 reminder cards rendered
Performance: Fast, instant load
```

## Summary

### What Changed
1. **More → Reminders & Routines:** Removed Upcoming tab, kept Routines + Settings
2. **Health → Today:** Replaced endless "Today's Schedule" with compact "Next Up" (1-3 items)
3. **Action Buttons:** Each reminder has direct action based on type
4. **Performance:** Only render next few reminders, not entire list

### What Stayed
1. **Countdown Cards:** Time-sensitive reminders still show countdown
2. **Routine Cards:** Still show next reminder preview (one line)
3. **Reminder Generation:** Logic still generates reminders from routines
4. **Notifications:** Push/local notifications still work
5. **Stores:** All data preserved in remindersStore and routinesStore

### Result
✅ Faster app  
✅ Cleaner UI  
✅ Actionable reminders  
✅ No endless lists  
✅ Better user experience
