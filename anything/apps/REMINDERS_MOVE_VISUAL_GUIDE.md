## 🔄 Navigation Flows

### Flow 1: Direct Access from More
```
More Tab
  ↓
Tap "Reminders & Routines" card
  ↓
Reminders & Routines Screen
  ├── Upcoming Tab (view all reminders)
  ├── Routines Tab (create/edit routines)
  └── Settings Tab (notification preferences)
```

### Flow 2: From Health Today
```
Health Tab → Today
  ↓
See time-sensitive countdown or schedule
  ↓
Tap "Manage your pet's care routine" info box
  ↓
Reminders & Routines Screen
  ↓
Create/edit routines
  ↓
Tap back button
  ↓
Returns to More Tab
```

### Flow 3: From Notification (future)
```
Receive notification: "Dinner in 30 minutes"
  ↓
Tap notification
  ↓
Opens Reminders & Routines Screen → Upcoming Tab
  ↓
See the specific reminder
  ↓
Complete or snooze
```

## 💡 Where to Go for What

### I want to... → Go to...

**Create a feeding routine**
→ More → Reminders & Routines → Routines tab → + button → Feeding

**See next reminder**
→ Health → Today (shows countdown card)

**View all upcoming reminders**
→ More → Reminders & Routines → Upcoming tab

**Turn off notifications**
→ More → Reminders & Routines → Settings tab

**Complete a reminder**
→ Health → Today (tap ✓ Done on countdown card)
OR More → Reminders & Routines → Upcoming (tap ✓ on reminder)

**Edit a routine**
→ More → Reminders & Routines → Routines tab → Tap routine → Edit

**Snooze a reminder**
→ Health → Today (tap ⏰ Snooze on countdown card)
OR More → Reminders & Routines → Upcoming (tap Snooze)
