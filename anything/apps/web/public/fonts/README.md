# Self-hosted fonts

Nunito (variable, wght 200-1000) and JetBrains Mono (400, 500), Latin + Latin-ext subsets, served from
our own origin so public pages make no request to Google. Both are SIL Open Font License 1.1
(licence texts alongside). Files come from the `@fontsource-variable/nunito` 5.3.0 and
`@fontsource/jetbrains-mono` 5.3.0 npm packages. The `@font-face` rules live in `src/app/global.css`.
